# Gestão de Obra – Kilamba Salas Comerciais
Plataforma de gestão e acompanhamento. Responsável: Exclusiv Arquitetura.

## Publicar
1. Crie um repositório no GitHub e envie estes ficheiros para a branch `main`.
2. Settings > Pages > Source: **GitHub Actions**.
3. A cada commit, o site é republicado automaticamente.

## Atualizar dados
Na plataforma (administrador): Config. > Exportar obra.json. Substitua `data/obra.json` no repositório e faça commit. A plataforma passa a mostrar os dados novos para todos.
